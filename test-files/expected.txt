# Regression baseline for the --decode-wav* harness. Tab-separated:
# filename<TAB>mode<TAB>min-decoded-packet-count.
# The runner accepts >= the threshold; FAILs if fewer packets decode.
#
# Modes:
#   fir    → --decode-wav (FIR antialias decimator → 12 kHz to BufferFull).
#            Exercises the Commit-C FIR. AFSK and IL2P-1200 etc. only.
#   native → --decode-wav-native (48 kHz raw to BufferFull, using48000=1).
#            Required for RUH/G3RUH 9600 because dw9600's demod is
#            hardwired to 48 kHz. Also handles AFSK adequately via
#            BufferFull's internal 4-skip downsample.
#
# Modem config comes from test-files/fixture/QtSoundModem.ini (the
# runner points QTSM_CONFIG_DIR at a temp copy of it):
#   ModemType1=1  (AFSK 1200)  on soundChannel1=1  (LEFT)
#   ModemType2=19 (RUH96)      on soundChannel2=1  (LEFT)
#   ModemType3=0  (SPEED_300)  on soundChannel3=1  (LEFT)
#   ModemType4=1  (AFSK 1200)  on soundChannel4=0  (disabled spare)
#   RXFreq1..4=1700, IL2P=1, IL2PCRC=1, FX25=1 on AX25_A..D
# Everything else is at getSettings() defaults.
#
# Re-baselined 28/09/2026 on mac-0.1.1 (db560e2) with the fixture; the
# counts reproduced the 2026-05-05 baselines exactly.
#
# Direwolf corpus (frames generated by direwolf 1.8.1 gen_packets; see
# the corpus README for arguments). Not listed because the fixture has
# no modem for them, so they always decode 0:
#   - 03 QPSK Direwolf <=1.5 (needs SPEED_DW2400, ModemType=12)
#   - 04 QPSK MFJ-2400 (SPEED_2400V26B, =14)
#   - 05 8PSK V.27 4800 (SPEED_8P4800, =13)
#   - 07 19200 G3RUH (no QSM speed slot)
#   - 08 EAS SAME (not implemented in QSM)
#
# Locked thresholds (observed in brackets):
