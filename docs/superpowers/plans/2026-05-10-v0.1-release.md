# mac-0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `mac-0.1.0`, the first tagged release of the QtSoundModem macOS port, as a GitHub Release with a built `.dmg`, SHA-256 checksums, and a curated CHANGELOG.

**Architecture:** Add `CHANGELOG.md` (Keep-a-Changelog) and a `.github/workflows/release.yml` that fires on `mac-*` tag pushes, builds the `.app` on a `macos-14` runner, wraps it in a `.dmg`, and publishes a GitHub Release. A small `scripts/extract-release-notes.sh` helper slices the changelog section for the pushed tag into the Release body.

**Tech Stack:** CMake, Qt 6, Homebrew, GitHub Actions (`macos-14` runner), `gh` CLI, `codex` CLI for second-reviewer gates.

**Spec:** `docs/superpowers/specs/2026-05-10-v0.1-release-design.md`

**Branch:** All work on `macos-port`. No new branch. Tag `mac-0.0.0-rc1` (throwaway) and `mac-0.1.0` are the only refs created.

```markdown
# Changelog

All notable changes to this fork are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

This fork starts at `mac-0.1.0`. Pre-fork history (upstream tags `0.64`–`0.76`, `24.45`) lives in [g8bpq/QtSoundModem](https://github.com/g8bpq/QtSoundModem); this file does not duplicate it.

## [Unreleased]

## [mac-0.1.0] – 2026-05-10

First tagged release of the macOS port. Builds and runs natively on Apple Silicon (macOS 14+), uses Qt 6 Multimedia for audio and libhidapi for CM108 PTT, and ships with a curated set of fixes — three of which also affect upstream.

### Added

- CMake build with platform-conditional sources, replacing the upstream Qt 5 `.pro` flow.
- arm64 / Apple Silicon support: POSIX serial / PTT shims (`MacBits.c`), `__ARM_ARCH` guards, native build on macOS 14.
- macOS bundle plumbing: ad-hoc codesigning the `.app` as a bundle, custom `.icns` icon, libfftw3f bundled into the `.app` for self-containment.
- `chdir` to `~/Library/Application Support/QtSoundModem` on launch; lazy-init global `QSettings` so config honours the new working directory.
- Native-rate audio capture with windowed-sinc FIR decimation to 12 kHz (replaces the older boxcar decimator).
- `--decode-wav` and `--decode-wav-native` offline decode harnesses, including a baseline-locked test corpus for regression checks.
- CoreAudio nominal-rate retune shim with `AutoRetuneSampleRate` INI flag — opportunistically aligns shared RX/TX devices to a 12 kHz multiple at the Devices-dialog accept, on hot-plug, and at startup; gated to avoid retuning while a stream is live.
- TX Audio / RX Audio gain sliders.
- View menu: PSK Constellation show/hide toggle.
- Tools submenu grouping Calibration and Restart Waterfall.
- Default CM108 VID/PID on the macOS hidapi path.
- README for the macos-port branch, with install / build / test notes; Homebrew tap documented as the preferred install route.

### Changed

- Migrated Qt Multimedia from Qt 5 to Qt 6; macOS default backend is now Qt audio + libhidapi.
- Bumped macOS deployment target from 11.0 to 14.0.
- Auto-track macOS Light/Dark appearance (replaces the upstream manual Dark Theme toggle).
- UI cleanup: widened the Devices dialog PTT Port, modem-option, and 6Pack Serial Port combos so labels are no longer clipped; re-flowed the Devices dialog rows for legibility; positioned DCD indicators against actual row geometry.
- Audio device persistence: persist by stable `QAudioDevice::id()` with description fallback; index reopen against the filtered device list; queued `audioInputsChanged` / `audioOutputsChanged` signals; serialised teardown vs. worker-thread TX/RX with a `QMutex`; closeQSound now tears streams down on device switch.
- Audio pipeline robustness: refuse non-decimator-friendly device rates and formats; bypass FIR decimation when `using48000` is set; skip the SoundFlush drain wait when the output sink is closed; broadcast mono input to stereo before decimation; dump input samples before `ProcessNewSamples` rather than after; PollQSound drains unconditionally and dumps post-decimation samples.
- `dw9600`: scale `lp_filter_size` by upsample for polyphase interpolation.
- CLI: canonicalise `--decode-wav` / `--dump-input` paths against startup cwd; fail loudly on `canonicaliseCliPath` errors.
- Force `NoRole` on Settings / View menu actions so macOS doesn't relocate them.
- RX offset control replaced with a spinbox so exact values (including 0) are reachable.
- Stop centring the window in macOS fullscreen; hug the right edge with the cluster.
- Suppress "Minimize to Tray" on macOS.
- Drop the redundant first-run microphone-permission dialog on macOS.

### Fixed

- **(also affects upstream)** Buffer overflow in AGW / frame monitor on long IL2P frames.
- **(also affects upstream)** PTT On/Off String parser silently treated values as hex; now auto-detects ASCII vs. hex so both forms work.
- **(also affects upstream)** AGW TX path and port-list use raw channel index, matching RX.
- Guard against negative `QIODevice::read` return in PollQSound.
- Tightened the `__ARM_ARCH` guard in `LinuxBits.c` so Apple Silicon builds compile cleanly.

### Removed

- `QFontDialog` font picker; the app defaults to the system font.
- Manual Dark Theme toggle (replaced by automatic Light/Dark tracking).
- Broken "Restart Waterfall" menu item.
- Windows-only build artefacts and source backups.

[Unreleased]: https://github.com/gm5dna/qtsoundmodem-macos-port/compare/mac-0.1.0...HEAD
[mac-0.1.0]: https://github.com/gm5dna/qtsoundmodem-macos-port/releases/tag/mac-0.1.0
```

- [ ] **Step 3: Write the extractor**

Create `scripts/extract-release-notes.sh` with this content:

```bash
#!/usr/bin/env bash
# Extract one CHANGELOG section into a Release-notes body.
#
# Usage: extract-release-notes.sh <changelog-path> <version>
#
# - For a stable version like "mac-0.1.0", emit the bullets under that
#   "## [<version>]" heading, stopping at the next "## [" heading or EOF.
#   Exit non-zero if no matching heading is found.
# - For a release-candidate version (contains "-rc"), emit the
#   "## [Unreleased]" section preceded by a one-line banner.
#
# Stdout is the body. No GitHub-specific formatting beyond Markdown.

set -euo pipefail

if [[ $# -ne 2 ]]; then
    echo "usage: $0 <changelog-path> <version>" >&2
    exit 2
fi

changelog="$1"
version="$2"

if [[ ! -f "$changelog" ]]; then
    echo "changelog not found: $changelog" >&2
    exit 2
fi

extract_section() {
    local heading="$1"
    awk -v h="$heading" '
        $0 ~ "^## \\[" h "\\]" { in_section = 1; next }
        in_section && /^## \[/   { exit }
        in_section               { print }
    ' "$changelog"
}

trim_blank_edges() {
    awk '
        NF { if (!started) started = 1; buffer[++n] = $0; next }
        started { buffer[++n] = $0 }
        END {
            # Find last non-blank line
            last = n
            while (last > 0 && buffer[last] !~ /[^[:space:]]/) last--
            for (i = 1; i <= last; i++) print buffer[i]
        }
    '
}

if [[ "$version" == *"-rc"* ]]; then
    body="$(extract_section "Unreleased" | trim_blank_edges)"
    if [[ -z "$body" ]]; then
        body="(no changes recorded in [Unreleased])"
    fi
    printf '> **This is a release candidate — not intended for production use.**\n\n%s\n' "$body"
    exit 0
fi

body="$(extract_section "$version" | trim_blank_edges)"
if [[ -z "$body" ]]; then
    echo "no CHANGELOG section for version: $version" >&2
    exit 1
fi
printf '%s\n' "$body"
```

- [ ] **Step 1: Create the workflow file**

Make the directory first:

```bash

```

Then write `.github/workflows/release.yml` with this content:

```yaml
name: Release

on:
  push:
    tags:
      - 'mac-*'

permissions:
  contents: write

jobs:
  build-and-release:
    runs-on: macos-14
    env:
      GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      VERSION: ${{ github.ref_name }}
      DMG_NAME: QtSoundModem-${{ github.ref_name }}.dmg

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Install dependencies
        run: |
          brew update
          brew install qt@6 fftw hidapi

      - name: Configure
        run: |
          cmake -S . -B build \
            -DCMAKE_BUILD_TYPE=Release \
            -DCMAKE_OSX_DEPLOYMENT_TARGET=14.0 \
            -DCMAKE_PREFIX_PATH="$(brew --prefix qt@6)"

      - name: Build
        run: cmake --build build --parallel

      - name: Bundle Qt frameworks
        run: |
          QT_PREFIX="$(brew --prefix qt@6)"
          "$QT_PREFIX/bin/macdeployqt" build/QtSoundModem.app

      - name: Ad-hoc codesign bundle
        run: |
          STAGE="$(mktemp -d)"
          cp -R build/QtSoundModem.app "$STAGE/"
          cd "$STAGE"
          codesign --deep --force --sign - QtSoundModem.app
          codesign --verify --deep --strict QtSoundModem.app
          mv QtSoundModem.app "$GITHUB_WORKSPACE/build/QtSoundModem.app.signed"
          rm -rf "$GITHUB_WORKSPACE/build/QtSoundModem.app"
          mv "$GITHUB_WORKSPACE/build/QtSoundModem.app.signed" "$GITHUB_WORKSPACE/build/QtSoundModem.app"

      - name: Build .dmg
        run: |
          STAGE="$(mktemp -d)"
          cp -R build/QtSoundModem.app "$STAGE/"
          ln -s /Applications "$STAGE/Applications"
          hdiutil create \
            -volname "QtSoundModem ${VERSION}" \
            -srcfolder "$STAGE" \
            -ov \
            -format UDZO \
            "$DMG_NAME"

      - name: SHA-256 checksums
        run: shasum -a 256 "$DMG_NAME" > SHA256SUMS

      - name: Extract release notes
        run: bash scripts/extract-release-notes.sh CHANGELOG.md "$VERSION" > release-notes.md

      - name: Append release footer
        run: |
          cat >> release-notes.md <<'FOOTER'

          ---

          ## Installing the .dmg

          The `.dmg` is ad-hoc signed (no Apple Developer ID) and will be quarantined by Gatekeeper on first launch.

          - Open the `.dmg`, drag `QtSoundModem.app` to `/Applications/`.
          - First launch: right-click (or Control-click) `QtSoundModem.app` in `/Applications/` and choose **Open** from the menu, then confirm the Gatekeeper prompt. Subsequent launches are normal double-click.
          - Alternatively, from Terminal: `xattr -d com.apple.quarantine /Applications/QtSoundModem.app`.

          ## Verifying the download

          ```
          shasum -a 256 -c SHA256SUMS
          ```

          ## Homebrew

          The Homebrew tap [gm5dna/amateur-radio](https://github.com/gm5dna/homebrew-amateur-radio) is the preferred install route and builds from source against `macos-port` HEAD.

          ## Links

          - [README](README.md)
          - [CHANGELOG](CHANGELOG.md)
          FOOTER

      - name: Determine pre-release flag
        id: prerelease
        run: |
          if [[ "$VERSION" == *"-rc"* || "$VERSION" == *"-alpha"* || "$VERSION" == *"-beta"* ]]; then
            echo "flag=--prerelease" >> "$GITHUB_OUTPUT"
          else
            echo "flag=" >> "$GITHUB_OUTPUT"
          fi

      - name: Create GitHub Release
        run: |
          gh release create "$VERSION" \
            --title "$VERSION" \
            --notes-file release-notes.md \
            ${{ steps.prerelease.outputs.flag }} \
            "$DMG_NAME" SHA256SUMS

      - name: Upload build log on failure
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: build-log-${{ github.ref_name }}
          path: build/
          retention-days: 7
```

## Out-of-band failure modes

These don't fit a step but are worth knowing:

- **Workflow fails on macdeployqt step:** likely Qt path resolution or a duplicate framework copy fighting with our CMake FFTW bundling (`bbe9e16`). Inspect the build log artefact, prune the redundant copy, push a fix to `macos-port`, then re-tag `mac-0.1.0` only after deleting the failed Release and tag.
- **Workflow fails on codesign step:** runner-side `$TMPDIR` differs from a local Mac. The signing-in-`$TMPDIR` lesson is about file-provider sync on a developer's machine — on a fresh CI runner, signing in `$GITHUB_WORKSPACE` is fine. If sign still fails, run `codesign --verify --verbose=4` from the workflow to see which framework objects rejected the signature.
- **gh release create returns 403:** the workflow's `GITHUB_TOKEN` lacks `contents: write`. The `permissions:` block at the top of the workflow grants it; if it's missing, the workflow YAML was edited out of compliance.
- **Empty release-notes.md:** the helper script's "stable version with no matching section" path exits 1 and fails the workflow, which is intended. If you see an empty body, the failure is upstream — check the extractor's stderr.

## Rollback

If anything is wrong with the published `mac-0.1.0`:

- **Minor:** Ship `mac-0.1.1` with the fix. Don't touch the published Release.
- **Severe:** `gh release delete mac-0.1.0 --yes --cleanup-tag` to atomic do-over. Note this breaks any link already shared, so reserve for genuinely broken artefacts. Then fix, re-tag.
